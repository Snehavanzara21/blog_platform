BlogVerse - Blog Platform with Comments

A full-featured blogging platform with user authentication, post management, and interactive commenting system.
Built as a comprehensive full-stack learning project.

Features

 Core Functionality
- User Authentication - Registration and login system
- Blog Post Management - Create, edit, and delete posts
- Comment System - Add and delete comments on posts
- User Interaction - Engage with content through comments
- Author Controls - Post authors can manage their content

User Features
- Create Posts - Write and publish blog posts
- Edit Posts - Update your own posts anytime
- Delete Posts - Remove your content when needed
- Add Comments - Share thoughts on any post
- Delete Comments - Remove your own comments or moderate if you're the post author
- View Posts - Browse all posts sorted by newest first

User Experience
- Clean, modern UI with smooth animations
- Modal-based post creation/editing
- Toast notifications for user feedback
- Responsive design for desktop, tablet, and mobile
- Real-time updates without page refresh

 Tech Stack
Frontend
- HTML5 - Semantic markup
- CSS3 - Custom styles with Flexbox and CSS Grid
- JavaScript (ES6+) - Vanilla JS for DOM manipulation
- Font Awesome  - Icon library
- Google Fonts (Inter) - Typography

Backend (Simulated)
- In-memory data store (demonstration)
- Client-side state management
- No external dependencies required

Installation & Setup
 Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: Local development server (VS Code Live Server, Python HTTP Server, etc.)
